**Activation:** "Almanac multimodal", "Almanac rollout", "turn this lesson into audio/slides/video/story/game/music", "responsive learning pilot". This is a repository-resident procedure, not a claim that it is installed as a runtime-level ChatGPT skill.

## Each request: select objective and purposeful transformation
1. Identify audience, learner goal, rights and source provenance, existing comprehension evidence, time and format constraints.
2. Locate one objective with reviewed claims. If unavailable, create design-only or openly draft example; do not invent source-derived content.
3. Score each modality on learning fit, incremental benefit, rights/safety, accessibility, measurable outcome, and cost. Choose a minimal credible set; six variants are not the default.
4. Draft a canonical explanation, original retrieval check and rationale; require qualified approval for exact clinical claims and answers.
5. Produce each chosen variant from the same objective and source IDs, with transcripts, notes, captions and alt text as needed.
6. Verify claims and assessment consistency across text, audio, video, slides, games, stories and mnemonic media. Changed versions need renewed review.
7. Create public excerpts only if they provide independent learning value and have public-use rights; invite the learner's next purposeful step without misleading product availability.
8. In the workspace preserve stable question/card IDs, FSRS, reviewer hashes, offline state and product entitlements. Proposed features are not deployed capabilities.
9. Evaluate reasoning, retention or transfer plus accessibility and voluntary learner feedback; do not equate views or playtime with learning.
10. Log actual status: READY / PILOT / BLOCKED / RESEARCH and recommend promote, revise or retire with evidence.

## Amateur-first criteria
- Story: can start as 3–5 PowerPoint slides with choice hyperlinks and debrief; fact-check and label fiction.
- Game: can start as lightweight standalone HTML with meaningful feedback, keyboard/touch access and a separate transfer task.
- Music: original 15–30-second mnemonic/rhythm for limited stable low-stakes items; text/silent alternatives, original composition and verified lyric meaning; no copyrighted melody, no automatic clinical simplification.
- Video: narrated slides with accurate terminology, captions and focused prompts can be sufficient.
- Audio: 2–5-minute original explanation, transcript, check question.
- PPTX: accessible, editable slides with speaker notes and source IDs.
Amateur production is acceptable; inaccurate or unlicensed teaching is never acceptable.

## Hard gates
No unapproved institution exam items, patient data, false clinical advice, guaranteed grade claims, unsupported claims of adaptive AI, unsolicited outreach or payment instructions. No unapproved live deploys/social posts/ad spend. New learner analytics require privacy and security controls. Declare honestly when a format exists only as a script or concept.

## Standard output
Objective, source credibility, media decision, public/private variants, artifacts actually created, release gates, experiment, next smallest build task and change log. Version the skill in reviewed PRs.
