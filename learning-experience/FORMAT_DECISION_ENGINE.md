# Format selection, public reach and private learning

**Use a format to improve a learning action, not to maximize output count.** Priorities: CORE = release quality now; PILOT = opt-in controlled experiment; RESEARCH = do not productize before evidence/feasibility and rights review.

| Format | Public 'first encounter' | Inside Almanac | Intended learning job | Priority | Failure mode / mitigation |
|---|---|---|---|---|---|
| Short vertical video | 20–60s useful example, question + answer | Quick introduction to a topic or misconception | Attention + concept orientation | CORE | Slick production without independent explanation; provide accurate script and captions |
| Segmented narrated video | Extract rights-cleared standalone snippet | Mechanism, worked example, procedure with checkpoints | Visual causal understanding | CORE | Passive autoplay; segment and prompt for reasoning, add transcript/poster |
| Audio overview / mini podcast | Short learner-focused recap with on-page text | Listen, pause, summarize and answer check | Convenient review and verbal explanation | CORE | Listening mistaken for mastery; provide transcript and follow-up retrieval |
| Slides / PPTX / PDF | 1–5-slide concept carousel, accessible image/text | 6–10-slide module map, speaker notes, download where included | Organize or compare concepts | CORE | Decorative deck with no teaching path; include notes, alt text, source IDs and original answer check |
| Written lesson / guide | Short accessible explainer | Structured source-linked lesson and review | Precision, searchable reference, slow reread | CORE | Wall of text; chunk and pair with questions |
| Infographics / concept maps | One self-contained visual | Explain relationships and causal dependencies | Visual organization | CORE | Unsupported arrow/cause; text alternative and reviewer-check each edge |
| Original quiz / exam rehearsal | One original problem and full rationale | Formative checks, item bank, simulations, feedback | Retrieval + transfer | CORE | Wrong or unreviewed keys; item review and why each option fails |
| Flashcards | Optional 1–3 recall cards | FSRS cards with context/why, app progress | Retrieval and spaced revisiting | CORE | Recognizing instead of remembering; hide answer and grade honestly |
| Story / illustrated case | 4-panel 'what would you do?' story | Authentic-seeming fictional narrative with reflective explanation | Context and decision reasoning | PILOT (high) | Story facts mislead; label fiction and tie scenes to approved objectives |
| Branching scenario / interactive dialogue | Two-choice microdecision with explanation | Consequence map and reflective rationale, multiple paths | Apply conditional rules and transfer | PILOT (high) | False clinical confidence / arbitrary endings; transparent simulated consequences |
| Microgames | One meaningful 30–90s learning interaction | Sort, sequence, map, diagnose misconception and retry | Repeated reasoning with immediate feedback | PILOT (high) | 'Points instead of learning'; score understanding not speed, optional no-timer mode |
| Original musical mnemonics / rhythm | Optional tiny original memory cue + plain text | Opt-in short mnemonic for bounded sequence/terms | Recall a small list or order | PILOT (narrow) | Catchy misinformation, unwanted music or distraction; test vs nonmusical retrieval, original composition/license |
| Choose-your-own-story adventures | Short 'choose a next step' prompt | A finite story arc with actual questions between scenes | Motivation + application | PILOT (medium) | Entertainment dilutes objective; each branch must earn its presence |
| Interactive diagrams / draggable ordering | Short visual challenge | Label sequence, process flow, cause/effect links | Visual applied practice | PILOT (medium) | Inaccessible drag-only UI; provide keyboard/tap and textual equivalent |
| Live classes / office hours | Event excerpt only if expressly authorized | Human coaching, clarification, worked examples | Social explanation and unresolved questions | RESEARCH | High operating cost and privacy recording |
| AR/VR | Rare original demonstration | Complex spatial/procedural rehearsal after validation | Spatial embodied practice | RESEARCH | Expensive, inaccessible, weak fit for most academic topics |
| Long-form music / ambient soundtrack | Avoid as default education claim | Optional non-instructional background only | Atmosphere, not verified learning | RESEARCH | Distraction, license/royalties, false 'focus music' promises |

## Music: a deliberate experiment, not a default medium
**Good candidate:** an exact, stable, short ordering rule, sequence or vocabulary set that learners repeatedly need to recall and that is not safety-critical when simplified. Create original words and melody or use clearly licensed music; always provide standard text and a silent pathway. Include a check requiring accurate explanation outside the song.
**Poor candidate:** diagnostic reasoning, nuanced exceptions, drug dosages, lists with changing recommendations, complex causal mechanisms; rhythm can camouflage caveats and harm transfer.
**Proof target:** delayed recall and ability to explain meaning versus a matched spoken/text mnemonic, plus opt-out rates. Evidence for musical mnemonics is promising in some contexts but heterogeneous; do not advertise guaranteed retention.

## Stories and games: explanation survives the fun
A story must contain (a) one objective, (b) a situation anchored in approved facts, (c) a decision with plausible choices, (d) feedback and rationale, (e) a transfer question. A game must make correct reasoning the fastest path to progress, not speed-tapping or random rewards. No public scoreboard of health, exam grades, identities or sensitive learner data. No gambling-style rewards or loot boxes.

## Selection rubric (0–3 on each)
1. Objective fit (0 = irrelevant, 3 = essential)
2. Clear learner benefit over simpler existing method
3. Source credibility, clinical safety and rights
4. Accessibility incl. usable alternatives and lower-bandwidth path
5. Demonstrable response signal (recall, explanation, transfer)
6. Cost/capacity to create and QA, scored inversely (3 = affordable)
Reject if evidence/rights/safety fails regardless of total. Recommend production when 5/6 scores >=2 and learning job is clear; opt-in pilot if uncertain but safe. Record rationale and alternative not selected.

## Practical defaults
- **All topics:** trustworthy concise text + original retrieval + feedback.
- **Most modules:** one visual explanation and optional narrated short video, according to package promise.
- **Audio and slides:** supporting versions, not separate unconnected truths.
- **Stories and games:** targeted features only after scored need/fit.
- **Music:** optional, highly selective and research-led, never as compulsory course requirement.
